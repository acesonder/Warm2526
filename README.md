# Warm2526 - Winter Warming Room Application

A responsive web application for managing a winter warming room facility with role-based access for clients, staff, and administrators.

## Features

- **Responsive Design**: Works seamlessly on mobile and desktop devices
- **Role-Based Access**: Three user types with tailored dashboards
  - **Clients**: Access to services, facility information, and assistance requests
  - **Staff**: Check-in/out management, inventory tracking, and activity logging
  - **Administrators**: Full system management, reporting, and configuration
- **AJAX Functionality**: Dynamic content loading without page refreshes
- **Minimal JavaScript**: Clean, efficient code with limited JS as requested
- **Modern UI**: Beautiful gradient design with winter-themed color scheme

## Technologies Used

- **HTML5**: Semantic markup structure
- **CSS3**: Responsive design with flexbox and grid layouts
- **JavaScript (Minimal)**: AJAX functionality and dynamic content loading
- **No external dependencies**: Pure vanilla JavaScript implementation

## Getting Started

1. Clone the repository
2. Open `index.html` in a web browser
3. Select a role to view the corresponding dashboard:
   - **Client**: See available services and request assistance
   - **Staff**: Manage daily operations and track activities
   - **Admin**: Access full system management and reporting

## User Roles

### Client Dashboard
- View facility information and temperature
- Access available services (meals, showers, clothing, etc.)
- Request assistance from staff
- See open hours and capacity

### Staff Dashboard
- Check in/out clients
- Dispense supplies and track inventory
- Schedule appointments
- View recent activity logs
- Monitor facility capacity

### Administrator Dashboard
- View comprehensive statistics and reports
- Manage staff and budget
- System configuration
- Inventory management
- Schedule shifts
- View alerts and notifications

## Mobile Responsiveness

The application is fully responsive and optimized for:
- Desktop (1200px and above)
- Tablet (768px - 1199px)
- Mobile (below 768px)
